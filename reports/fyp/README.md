# FYP Reports

This area contains compact, traceable evidence for the assessed Year 3 Project.
Do not move or rewrite the existing summer reports elsewhere under `reports/`.

- `baseline/` contains compact reproduced baseline evidence and setup status.
- `experiments/` contains one directory per FYP experiment, named with its
  experiment ID.

Large Vivado/XSim generated trees, caches, checkpoints, wave databases and
bitstreams should not be committed or copied to OneDrive. Retain the concise
reports required to reproduce and audit each recorded result.

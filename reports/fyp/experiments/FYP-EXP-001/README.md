workload characterisation:

- raw compact test outputs;
- cycle and counter summaries;
- benchmark CSV extracts;
- plots and tables; and
- analysis notes.

Every reproduced result must record its Git SHA, testbench, top module, command,
tool version and PASS/FAIL status. Retained summer values must remain labelled
`prior_work_reference`; new controlled runs use
`reproduced_fyp_measurement`.

trees or other large generated output here. Keep only compact evidence needed
for audit and analysis.
